# Security Policy

## Reporting
Report vulnerabilities via GitHub private vulnerability reporting
(Security tab → "Report a vulnerability"). Do NOT open public issues for
exploitable bugs.

## Scope
Smart contracts, keeper bots, APIs, and frontend in this org.

## PGP / contact
Security contact will be published before mainnet. Testnet phase:
use private vulnerability reporting only.

## Never
Never commit private keys, mnemonics, or RPC endpoints with credentials.
gitleaks runs on every push.
