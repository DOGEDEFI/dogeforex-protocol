# dogeforex-protocol

Collateralized FOREX stablecoin protocol for DogeOS — 7 currency instances (K9USD…K9BRL) from one parameterized Frankencoin-fork codebase.

Mechanism descended from [Frankencoin (ZCHF)](https://github.com/Frankencoin-ZCHF/FrankenCoin) — MIT license, audit lineage tracked in `docs/LINEAGE.md` as the codebase matures.

Status: **MVP in development** on DogeOS Chikyū testnet (chain 6281971).
